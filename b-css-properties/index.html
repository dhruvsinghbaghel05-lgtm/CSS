CSS Properties

Selectors :

  1. Universal Selector : *{}
  2. Element Selector : nameofelement{}
  3. Class Selector : .classname{}
  4. ID Selector : #idname{}

Color Systems :

  1. Color: The text color of the element.
  2. Background-color: The background color of the element.
  • Color Systems : There are several color systems used in CSS, including:
    • Hexadecimal: A six-digit code representing the red, green, and blue (RGB) values of a color. For example, #FF0000 represents red.
    • RGB: A color model that uses the red, green, and blue components to define a color. For example, rgb(255,0,0) represents red.
    • RGBA: Similar to RGB but includes an alpha channel for opacity. For example, rgba(255,0,0,0.5) represents a semi-transparent red.

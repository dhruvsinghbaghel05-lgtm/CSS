  1. height
  2. width

Height

By default, it sets the content area height of the element

        div {
    height: value;
}

Width

By default, it sets the content area width of the element


        div {
    width: value;
}

Padding

By default, it sets the padding of the element , it is used to adjust the space between the content and the border
It is given clockwise order (top, right, bottom, left) 


        div {
    padding: top right bottom left(in pixels or percentage);
}

Border

By default, it sets the border of the element
border-width : 2px;
border-style : solid / dotted / dashed
border-color : black / red / green
border-radius : it is used to make corners of the border rounded. It can take values in pixels or percentage. 

div {
    border-width: value;
    border-style: value;
    border-color: value;
    border-radius: value;
    
}

CASCADING STYLE (CSS)

It is a language which is used to describe the style of the webpages

Basic Syntax

selector {
    property: value;
}

Methods of Adding CSS

1. Inline CSS

    <h1 style="color:blue;">This is a heading</h1>

2. Internal CSS

    <head>
    <style>
    h1{
    color:blue;
    }
    </style>
    </head>
    <body>
    <h1>This is a heading</h1>
    </body>

Flex Sizing

It is used to set the initial main size of the flex item either grow or shrink it.

If the flex direction is "Row" then the flex sizing will apply on width & if the flex direction is "column" then the sizing will applied on height

Properties in flex sizing :

  1. flex-basis
  2. flex-grow : Values
    • 1 - one times
    • 2 - two times
    • 3 - three times
  3. flex-shrink
    • 1 - one times
    • 2 - two times
    • 3 - three times
